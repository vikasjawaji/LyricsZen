Engineered for Excellence

Why Music Lovers Choose LyricsZen

Designed to feel like an organic, native part of YouTube Music™ with uncompromising audio purity.

Sub-50ms Synchronized Tracking

Unlike standard extensions that poll audio only 4 times a second, LyricsZen runs a high-precision 50ms engine. Lines activate on the exact vocal beat.

Intelligent 3-Tier Lyrics Engine

Automatic cascading fallback checks YouTube timed lyrics → LRCLIB time-synced → YouTube static cards → Plain lyrics → Lyrics.ovh. You never get a blank screen.

Flawless Center Alignment

Whether text size is set to 18px or 96px, mathematical center scrolling ensures lyrics are locked dead-center in the viewport with zero layout jitter.

100% Native Audio Purity

Zero Web Audio API hooks, zero frequency-filtering DSP, and zero gain alterations. Your high-res audio streams directly from YouTube Music untouched.

Party Edge Visualizers

Cinematic edge perimeter audio visualizers (Bars, Dots, Twinkle, Wave, Pulse) that react smoothly to the rhythm without blocking lyric readability.

Zero Tracking & Full Privacy

Runs strictly within your browser's isolated Shadow DOM. No user data, analytics, or listening habits are ever collected, tracked, or transmitted.

Quick Setup

Install LyricsZen in 30 Seconds

Follow these quick steps to load LyricsZen directly into Chrome or any Chromium browser (Edge, Brave, Arc, Opera).

1

Download or Clone

Clone the repository or download the ZIP from GitHub:

git clone https://github.com/vikasjawaji/LyricsZen.git
2

Open Chrome Extensions

In your address bar, navigate to chrome://extensions and toggle Developer mode in the top-right corner.

3

Load Unpacked Extension

Click Load unpacked and select the LyricsZen folder. Navigate to music.youtube.com and enjoy your lyrics!
